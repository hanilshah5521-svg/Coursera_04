GitHub assignment submission checklist

1. Upload CODE_OF_CONDUCT.md to the root of your public GitHub repository.
2. Upload CONTRIBUTING.md to the root of your public GitHub repository.
3. Upload simple-interest.sh to the root of your public GitHub repository and make it executable if testing locally: chmod +x simple-interest.sh
4. For Task 3, submit the public URL ending in /CODE_OF_CONDUCT.md.
5. For Task 4, submit the public URL ending in /CONTRIBUTING.md.
6. For Task 5, submit the public URL ending in /simple-interest.sh.
7. Tasks 6–9 require real command output from your own repository. Replace the evidence placeholders in the respective text files with the contents of your saved evidence files before submitting.

URL format examples (replace OWNER and REPO with your actual GitHub account and repository):
https://github.com/OWNER/REPO/blob/main/CODE_OF_CONDUCT.md
https://github.com/OWNER/REPO/blob/main/CONTRIBUTING.md
https://github.com/OWNER/REPO/blob/main/simple-interest.sh
